# TrenchScan

**Scan first. Ape second.**

TrenchScan is a real-time Solana launch scanner for degenerates with questionable risk tolerance. It watches fresh launches and turns messy on-chain activity into fast, explainable signals.

## What we're building

The first milestone is deliberately narrow: detect a new Pump.fun launch from Solana itself and surface it in TrenchScan within seconds.

From there, the analysis layer will add:

- creator / dev history
- early-buyer analysis
- holder concentration
- wallet funding links and clusters
- coordinated launch activity
- explainable risk signals

No mystery AI scores. Every signal should be traceable back to on-chain evidence.
